# Extraction verification portal

A standalone, no-server page to **eyeball each receipt against what the OCR
captured**, confirm or correct each field, and export a human-verified gold set.
The diff between "OCR captured" and "you confirmed" is also the real accuracy
number.

## Use it

1. **Build / rebuild** (copies `demo-receipts/` → numbered images, runs the
   production extractor on all of them, regenerates `index.html`):
   ```bash
   python3 eval/portal/build.py --model gpt-4o
   ```
2. **Open** `eval/portal/index.html` in a browser (double-click, or
   `file://…/eval/portal/index.html`). No server needed.
3. For each receipt: image on the left, captured fields on the right. Per field:
   - **✓ correct** — captured value is right as-is.
   - **✗ wrong** — reveals a box; type the correct value. (Leave blank = the
     true value is null/none.)
   - optional per-field note. Plus an overall comment box.
   - **Mark verified ✓** advances to the next receipt.
   - Progress auto-saves in the browser; ‹ › or arrow keys navigate; click the
     image to zoom.
4. **Export verified JSON** → downloads `verified-labels.json`. Send it back; it
   folds into `eval/labels.json` (keyed by original filename) and we re-run
   `eval/score_models.py` for real, human-grounded accuracy numbers.
   **Import** reloads a previous export to resume.

## Deploy online (encrypted, passcode-gated)

For a remote reviewer. `seal.mjs` bundles data + images into one AES-256-GCM
file (no loose image URLs); decryption is client-side on passcode entry.

```bash
node eval/portal/seal.mjs --passcode "your-passcode"     # → eval/portal/index-deploy.html
# deploy that one file as a standalone STATIC project (not the Next app):
mkdir -p /tmp/spendsilo-verify
cp eval/portal/index-deploy.html /tmp/spendsilo-verify/index.html
printf '{"version":2,"framework":null,"buildCommand":null,"outputDirectory":"."}' > /tmp/spendsilo-verify/vercel.json
vercel deploy --prod --yes --scope yourdesigncozas-projects --cwd /tmp/spendsilo-verify
```

Live: **https://spendsilo-verify.vercel.app** (Vercel project `spendsilo-verify`,
separate from the invoice-ocr app). Reviewers are the invoice owners themselves,
so the passcode is just a light gate, not high-security.

## Notes

- Images are renumbered `001…NNN` for easy eyeballing; `manifest.json` maps each
  number back to its original `demo-receipts` filename. Export uses the original
  filenames so the scorer maps correctly.
- `captured.json` = raw OCR output per receipt (audit trail).
- Everything here except the source images is regenerated by `build.py`.
